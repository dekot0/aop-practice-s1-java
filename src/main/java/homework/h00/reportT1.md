### Задача №1: Найменше спільне кратне (LeetCode 2413)
 **Суть:** Програма приймає число `n` і знаходить мінімальне число, яке одночасно ділиться і на `2`, і на `n`. Якщо вхідне число вже є парним (`n % 2 == 0`), алгоритм повертає його ж. Якщо воно непарне, ми просто множимо його на 2. 5=10
 
 **Навіщо це в житті (Бойовий кейс):** Цей алгоритм потрібен для **синхронизації таймерів та обладнання**. Наприклад, коли сервер бекапу працює з фіксованим інтервалом у 2 хвилини, а зовнішній датчик прокидається кожні `n` хвилин. Програма моментально знаходить оптимальну спільну хвилину для їхнього одночасного опитування, щоб дані не рассинхронізувалися.

 Тепер головне це запам'ятати.
